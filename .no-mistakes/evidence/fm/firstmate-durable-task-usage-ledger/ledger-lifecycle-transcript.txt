Firstmate durable task-usage ledger - end-to-end operator transcript
Every command below is a real bin/fm-*.sh run against a sandbox home
($DEMO/home). The forge and the terminal backend are stubbed; the spawn,
PR-check, merge, teardown and ledger code paths are the real ones.

=== 4. Replaying those calls is idempotent by event identity ===

$ bin/fm-pr-check.sh 'ledger-demo-x1' 'https://github.com/acme/acme-api/pull/138' >/dev/null 2>&1; bin/fm-pr-merge.sh 'ledger-demo-x1' 'https://github.com/acme/acme-api/pull/138' >/dev/null 2>&1; echo 'replayed the PR registration and the merge notification'
